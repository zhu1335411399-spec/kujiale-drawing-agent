# 验收计划（未执行记录）

| 用例 | 通过条件 |
|---|---|
| 双账号同 tabId | pageId 仍可区分，读取不串页 |
| 同名或切换客户配置 | 重新定位并核对归属 |
| 修改保存 | 业务结果及服务器回读吻合，未发布 |
| 保存超时 | 先核对实际状态，不盲目重复写入 |
| 前端更新 | 图纸&清单中设置→更新配置完成，再验图 |
| 自动标注 | 更新后编辑视图→自动标注，再核对新标注 |
| 已有手动标注 | 额外覆盖不超出用户授权 |
| 独立发布 | 明确发布任务、已保存且无新增修改、范围及结果可核验 |
| 换电脑 | 安装路径重新生成，无配对码，无旧机凭据 |

本表是验收标准，不是通过记录。真实执行后单独新增脱敏记录，说明版本、时间、输入、结果及限制。
