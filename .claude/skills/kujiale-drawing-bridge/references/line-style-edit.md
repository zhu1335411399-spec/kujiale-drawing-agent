# 搜索、编辑与独立保存线样式

## 选择正确工具

| 需求 | 工具 | 结果边界 |
|---|---|---|
| 查看当前分页 | drawing_list_line_styles | name 只是当前页本地过滤 |
| 在网页搜索名称 | drawing_search_line_styles | 使用实际搜索框，遍历搜索结果分页 |
| 修改指定记录 | drawing_update_line_style | 只改 changes 中字段，返回未保存的编辑回执 |
| 保存本轮编辑 | drawing_save_line_style | 核对回执和列表，保存提示后刷新回读 |

这些工具属于同一施工图 MCP 服务，不为每个动作启动一个服务。父级流程负责串联工具。搜索和编辑不调用未验证的业务接口，不解码或回放捕获的请求体。

## 搜索与定位

1. 从 drawing_get_context 取得本轮配置 pageId，精确核对 expectedConfigName 和 expectedCustomerName。后者是“来自于”标签，不是登录操作员名称，也不是账号 ID。
2. 搜索工具传 query、match=exact 或 contains，maxPages 默认 10。query 为空字符串表示清除搜索。必要时工具切换到实际观察到的“线样式”子标签。
3. 返回完整字段 id、name、lineType、scale、color、widthMm，并报告 pagesRead、complete。complete=false 时只能称为部分结果，不能据此判定不存在或唯一。
4. 同名记录通过返回的行 ID 和原字段快照区分。不得靠结果序号、模糊名称或旧 ID 猜选。工具通常返回结果第一页，不保证保留用户原筛选视图。
5. referenceUsage=unknown 表示对象配置、注释等引用范围尚未读取。不能把搜索结果当作引用关系盘点，也不能宣称更改样式只影响当前列表。

## 编辑合同

将搜索返回的完整记录原样传入 expectedStyle，并为本次任务创建唯一 requestId。changes 只包含需要修改的字段：

| 字段 | 输入规则 |
|---|---|
| name | 非空名称，最多 100 字符；全列表检查重名 |
| lineType | 页面关联下拉实际存在的准确名称 |
| scale | 正数字符串；最终线型为 CONTINUOUS 时禁止设置 |
| colorIndex | 0–255 的 CAD 索引色字符串，不接受 RGB |
| widthMm | 正数字符串；必须为关联线宽下拉的实际选项 |

工具先读取完整线样式列表，核对原值和只读锁，再按 ID 编辑。完成后按新名称与同一 ID 回读，并检查其他线样式记录未改变。超过分页上限、原值变化、目标切换或控件不唯一时停止。

名称、比例和颜色使用扩展限定的浏览器输入通道提交，避免受控输入框只改变表面文字。首次部署工作线程更新后，需要重新加载实际 Chrome/Edge 扩展；重新连接不会加载新代码。该通道使用扩展已有的 debugger 权限，仅针对已绑定配置、行和授权字段；无法附加时先报告原因，不调整账号权限或断开别人的调试连接。

只有 status=style-fields-verified 或 unchanged 才是成功编辑结果。saved=false 是尚未保存，receiptId 绑定本页、本配置与本次变更。

## 独立保存与结果验收

用户任务包含配置修改时，编辑完成后调用 drawing_save_line_style，传入同一 pageId、目标名称及 receiptId。工具先核对完整列表未继续变化，记录保存尝试，然后点击一次保存。出现确认框时，必须精确匹配“确认将基础配置[配置名]保存在[客户名]?”后才点击框内保存。观察到新的保存成功提示或同一客户配置的保存时间更新，才刷新页面并按名称、ID 和所有字段重新搜索。

只有 saved=true、persistedReadback=true 才能报告“保存反馈与刷新回读通过”。serverApiVerified=false 明确表示没有独立服务器 API 的持久化证明。保存不包含发布、前端更新配置或图纸验收；这些状态另报。

网页刷新可能回到操作员自己的配置。只有回执证明本轮已保存且页面确实回到“你的账号”时，工具才重新载入原客户一次，再检查原配置名称和同一行 ID；不会选择其他模板或再次保存。若返回其他客户、候选不唯一或默认配置不同，则停止并保留待核验。载入防重记录按网页文档区分，刷新后可重新载入，同一文档内仍阻止不确定提交的重复。

保存按钮是配置级操作。工具可比对本次前后的线样式，无法发现所有其他分类的手工未保存修改；不得宣称只提交了一行或所有分类均无并发变更。此工具也不能拿来保存其他分类。

## 部分失败与恢复

- needs-review 可能留下部分修改。先搜索实际行和字段，不新建第二行，不沿用旧快照继续。
- request-already-used 表示该任务已有记录；先核对 previousStatus 和实际结果。不要换 requestId 来盲目重放。
- 保存已尝试而结果不明时，不重复点击保存或刷新；先只读核对结果。缺少新成功提示时保留“保存未确认”。
- 如果已打开匹配的客户保存确认框，可凭原回执完成这个待确认步骤，不再点击顶部保存。确认已提交后只用回执记录的原保存时间核对变化和字段，该分支不会再次提交保存。缺少回执基线或结果不明时保留待确认；调用方不能凭空指定成功证据。
- 目标、字段和未修改记录均重新确认后，才为明确剩余修改创建新任务。没有修改时不为获取回执而重复写入。
- 复制、删除、批量导入、引用关系读取和前端更新均不是本工具的附带功能。
