# 工具清单与实际边界

| 名称 | 职责 | 已有证据 | 尚未完成 |
|---|---|---|---|
| drawing_get_context | 双端页面上下文 | 已实现；本机脚本经既有 MCP 处理器读到双浏览器页面 | 当前聊天客户端直接接入、身份和客户归属核验 |
| drawing_read_config | 配置名称、状态、来源显示 | 状态与来源文字已实读 | 配置名称曾返回空；账号 ID、归属 ID 未核验 |
| drawing_list_line_styles | 当前已渲染线样式，默认 10 行 | 当前网页第 1 页数据已实读 | 网页搜索自动触发、跨网页分页采集、选项枚举 |
| drawing_save_config | 保存，不发布 | 已注册；只读目标核对后返回未执行 | 执行适配器及持久化回读 |
| drawing_publish_config | 用户明确要求时独立发布 | 已注册；只读目标核对后返回未执行 | 执行适配器及发布结果回读 |

name 参数只是当前网页已渲染记录的本地子串过滤，不等同于网页“搜索线样式名称”。空结果不证明全部配置中不存在。
个性化样式与通用字段、搜索补查和固定选项规则见 [线样式合同](line-styles.md)。
前端更新配置、自动标注、另存为、出图和恢复尚没有已验证的自动执行工具。工具名、模拟测试、收到调用和真实业务成功分别报告。
