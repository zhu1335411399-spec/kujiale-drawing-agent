# 施工图桥接管理器 0.6.0

Windows 本机常驻托盘程序，统一检测 Chrome 后端、Edge 前端、宿主注册、服务与最近 MCP 调用。

- 安装目录双击 DrawingBridgeManager.exe，关闭窗口缩到右下角托盘；托盘菜单可以退出。
- 点击“修复接入”会对当前安装执行宿主注册并回读检查；失败时保留错误，不显示已连接。
- 修复后需要在两个浏览器分别重新加载扩展。管理器不能代替首次浏览器安装确认或个人账号登录。
- 两浏览器扩展上报真实页面快照，超过 15 秒没有新心跳时清空页面，窗口超过 10 秒没有新读数时清除旧页面显示。
- 注册正常不代表扩展已接入；扩展接入不代表目标页面打开；设计器可访问不代表“图纸&清单”、客户归属或企业模板已核验。
- 当前管理器不修改配置，不执行保存或发布，也不自动设置开机启动。

源码需要 Node.js 20+ 和 Windows .NET Framework；完整包自带 Node 和已编译的 WinForms 程序。

本机断连前已生成原型程序；最终版本以 GitHub Windows 构建、协议回归和宿主注册回读测试结果为准。用户电脑上的实际注册和双浏览器心跳仍需现场验证。
