# 对象配置：属性、显示样式与验收

## 业务位置与分类

对象配置为不同对象的真分类提供全局默认参数，供视图配置继承或自定义维护。按实际页面读取大类及层级，不把同名真分类在不同大类中的记录合并。名称与行 ID 必须共同绑定；不要用行序号或搜索命中的第一项代替定位。

2026-11-19 在实际页面完整遍历大类下拉框，读到 19 类：建筑结构、装配式装修、参数化吊顶、施工图、水电、硬装、软装、定制门窗、定制厨柜、定制衣柜、定制衣柜-副本、定制厨柜-副本、定制门窗-副本、照明设计、平面布置、软装（coohom特有）、新自由造型、筑多维、BOM。这是当次页面清单，不是平台永久固定全集。显示样式和对象属性分别读取自己的选中大类。

## 属性与继承

| 属性 | 实际控件与含义 | 验收条件 |
|---|---|---|
| 可选择性 | 勾选框；用户说明勾选后可在编辑视图中选中 | 使用正确企业模板、更新配置后实际选中对应对象 |
| 可剖切性 | 剖切方式选择，不是布尔勾选框；选项为剖到显示截面、剖到显示整体、剖到不显示 | 在实际立面范围线剖到对象的场景下分别检验，不能用平面图截图代替 |
| 立面图侧面不显示 | 独立勾选框 | 同一对象、正确朝向和对应立面视图中对照显示结果 |

每项属性分别有自定义/随上级菜单。自定义影响对象自身，后续需定位对象修改；随上级继承父对象。菜单未标记选项时返回 `unmarked`，不猜为自定义或随上级。编辑时必须明确 `mode:custom` 及值，或 `mode:parent`；parent 不传自定义值。`请选择` 是未选择的页面文字，不是有效剖切方式。

大类行的 `(已配置数 / 总数)` 会随子类配置更新。这是界面统计，不能误认成父对象属性被写入；仍须比较父行勾选值及剖切选择是否变化。修改父对象可能影响继承后代，不能宣称只影响一行。

## 显示样式与样式库

| 分组 | 字段 | 替换来源与边界 |
|---|---|---|
| 表面设置 | 造型线、轮廓线 | 线样式库；替换引用与编辑共享线样式是两个动作 |
| 表面设置 | 表面填充、遮罩 | 填充不属于线样式；遮罩单独控制 |
| 截面设置 | 截面线 | 线样式库，不能与表面造型线混为一列 |
| 截面设置 | 截面填充、遮罩 | 填充不属于线样式；遮罩单独控制 |

浅底、深底分别定位。真实页面已读取线样式替换抽屉，包含原引用、带 ID 的候选记录、分页、新建样式、取消及替换。候选从第 1 页开始完整遍历，名称不唯一、分页不完整或目标 ID 变化时停止。只改引用，不改共享线样式本身。

用户说明填充栏仅提供替换、不支持在该栏新建；这条规则不等于已完成填充写入验收。引用替换栏内新建线样式的完整流程仍待适配，可用线样式工具不代表此入口已接通。

## 工具与操作顺序

1. `drawing_get_context` 读取当前后端；来源、模板名称或状态未知时，先只读检查，不猜配置。对象页可能同时有模板和大类两个下拉框，不依赖动态 rc_select 序号识别模板。
2. `drawing_inspect_object_config` 读取或打开对象页，切换对象属性/显示样式、枚举大类、搜索真分类、按原 ID 展开子层级。结果范围是当前渲染树；折叠后代、分页或虚拟列表不能据此称为全量对象盘点。
   真分类搜索实际提交网页搜索按钮；结果树可能包含祖先和后代，不要求每一行名称都包含查询词。真实页面已搜索墙并按原 ID 唯一定位，不能用本地名称过滤代替网页搜索。
3. 使用 `read-properties` 读取完整三属性快照（包括继承模式），再调用 `drawing_update_object_properties`，只传指定变更。以大类、真分类 ID、名称、客户来源、模板和状态共同绑定。
4. 使用 `drawing_replace_object_line_style` 替换一个明确主题、明确列中可直接替换的引用。需要原单元格文字与目标样式准确名称；当前不自动把继承引用切换为自定义，不适用于填充。
5. 汇总本轮 `receiptId`，独立调用 `drawing_save_object_config`。核对客户保存确认框和更新的保存时间；刷新后回到操作员配置时，仅恢复原客户及原选中模板，再按大类、ID、字段和预览回读。确认已提交后只核验，不重复保存。不自动发布。

每个请求使用唯一 requestId，恢复同一任务不更改参数。属性修改遇到统计变化时可以只读核对后完成回执，不重新点击勾选。新请求不得用于掩盖结果不确定的旧写入。保存为配置级动作，工具不能排除其他分类中所有手工未保存变更。

## 大类显示同步及父级引用变更

切换对象属性/显示样式时，下拉显示名称与表格根行可能暂时不一致。操作器需同时核对已选名称和当前大类根行；仅下拉名称正确不能继续写入。分类列表从顶部遍历，等待实际表格对应到目标大类后才定位真分类。

替换大类根节点的线样式引用，会传播到随上级的可见后代。只允许目标线列变化：原后代无独立替换入口，后代仍在原大类、ID 和列结构不变，目标列文字及实际 SVG 颜色/线型/宽度与根节点一致，其他列和勾选保持不变。自定义引用、其他列、预览不符或节点变化继续阻止保存。原请求已替换但因继承变化待复核时，仅重新比较记录，不再执行替换。
