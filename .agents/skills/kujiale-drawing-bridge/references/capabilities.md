# MCP 能力分组

本表记录源码能力与真实页面证据，不用模拟测试数量代替业务验收。

## 页面读取与定位

| 工具 | 能力 | 边界 |
|---|---|---|
| drawing_get_context | 获取已连接页面、配置名称与来源显示标签 | 标签不等于账号 ID 或客户归属证明 |
| drawing_read_config | 读取当前配置、可见导航与控件结构 | 不代表其他分类的数据读写已实现 |
| drawing_list_line_styles | 读取线样式实际字段 | 仅当前已渲染网页分页；name 是本地子串过滤 |

以上读取工具已在真实页面调用。切换账号、配置或页面后重新读取。

## 前端账号显示核对

| 工具 | 能力 | 当前证据 |
|---|---|---|
| drawing_read_frontend_identity | 按浏览器和设计页定位右上角头像，读取 title 或悬停提示并比较企业名称 | 真实 Edge 头像悬停已读取企业名称和页面账号 ID，名称与同次 Chrome 后台来源匹配；不据此推断后台客户 ID |
| drawing_read_frontend_account | 与扩展侧栏共用单次检测、缓存及并发合并；普通设计页账号与工作区状态分开读取 | 普通设计页的名称和 ID 已真实读取；新增共享工作线程需重载扩展后继续核验，不从源码注册推断已加载 |

Chrome/Edge 会话类型已在真实桥接中分别读取。名称核对不代表真实账号ID、模板或版本已验证。操作合同见 [头像名称核对](frontend-identity.md)。

## 已实际执行的线样式操作

| 工具 | 能力 | 边界 |
|---|---|---|
| drawing_new_line_style | 单击新建并尝试返回默认行 | 曾返回结果不确定，需另行回读；不要盲目重复 |
| drawing_create_line_draft | 通用新建并设置名称、线型、颜色索引、线宽，回读字段 | 不保存、发布或重载；比例保留网页默认值 |

草稿流程已在真实页面完成：名称为测试输入、线型 DOT、颜色 255、线宽 0.09 mm；
另行读取页面确认相同结果。此证据不代表全部选项、所有账号和所有页面版本都已验证。
读取 [线样式新建流程](line-style-create.md) 后执行。不要把线样式能力推广成对象、注释或其他分类已支持。

## 线样式搜索、编辑与回执保存

| 工具 | 能力 | 真实页面证据 |
|---|---|---|
| drawing_search_line_styles | 实际网页名称搜索、精确或包含匹配、逐页读取及完整性标记 | 已读取跨页列表，并按改名后的名称及相同行 ID 找到测试行 |
| drawing_update_line_style | 完整原值快照和行 ID 绑定，只改指定字段，检查未修改记录 | 已在同一测试行完成名称、DASHED、比例 200、颜色 251、线宽 0.09 的页面回读 |
| drawing_save_line_style | 独立保存编辑回执，精确核对客户确认框，成功反馈后刷新回读 | 真实客户确认保存、保存时间更新、刷新后重新载入原客户及同 ID 字段回读通过；不宣称独立服务器 API 已验证 |

读取 [搜索编辑流程](line-style-edit.md)。名称、比例、颜色使用限定浏览器输入；网页新成功提示或保存时间更新与刷新后的字段共同构成保存证据。引用关系未知，保存按钮是配置级动作，不能自动排除其他分类的手工未保存修改。

| drawing_update_annotation_style | 已在新建文本测试样式上将字号从 16 改为 4，重新打开同 ID 验证，其余已读取字段不变 | 独立重命名未实测；引线、尺寸、标高规范字段写入尚未适配 |
| drawing_save_annotation_styles | 四类新建和连续文本编辑回执已统一保存，保存时间更新、刷新后重载原客户并按 ID、名称、字号回读通过 | 不发布；未独立验证服务器 API，未验证前端应用效果 |

2026-11-19 完成上述四类新建、实际名称搜索、文本字号编辑和保存后的真实页面回读。新建是名称向导及规范面板两步，使用绑定任务的浏览器输入通道；修改源码只开放改名入口与文本字号，改名不能因字号成功而视为已验收。调用合同及证据边界见 [注释写入流程](annotation-write.md)。

## 实验与占位能力

- drawing_create_line_style：旧 MCP_TEST_ 测试入口，包含保存尝试，不作通用入口使用。
- drawing_create_line_style_and_save：实验性完整流程，仍有全列表展示限制，未完成真实保存验收。
- drawing_save_config、drawing_publish_config：当前返回未执行或目标不匹配，不具备已验证的写入能力。
- 已有线样式编辑和回执保存使用上节工具；复制、删除、DWG/DXF/CTB 批量导入尚未形成已验证通用工具。
- 对象配置超出上节已验证字段的范围，以及标注配置、视图、表格、图纸、下载、参数、页面、其他配置、历史版本：不能从导航可见或样式局部能力推断已支持。
