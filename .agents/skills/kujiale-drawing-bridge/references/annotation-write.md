# 注释样式新建、搜索、修改与保存

## 当前合同

这些工具与线样式工具属于同一施工图 MCP 服务。先从 drawing_get_context 绑定 pageId、客户来源及配置名称，再按用户授权操作。四类名称为 text、leader、dimension、elevation，不能从客户样式名称推断类别。

| 工具 | 行为 | 边界 |
|---|---|---|
| drawing_search_annotation_styles | 在指定分类的真实网页搜索框输入名称并回读 ID、名称及 complete | 当前结果超过可完整读取范围时返回不完整；不自动遍历全部分页 |
| drawing_create_annotation_style | 点击一次新建，输入名称、下一步、检查本分类规范面板、保留默认规范并完成，回读新 ID | 不保存或发布；当前名称向导显示 50 字符限制，禁止重复不确定的新建 |
| drawing_update_annotation_style | 按原 ID 和名称快照定位，尝试保留 ID 改名；文本分类支持 fontSize 字符串及编辑后重新打开面板回读 | 仅明确支持的字段；其他三类规范参数仍待适配；独立改名路径以实际回读为准 |
| drawing_save_annotation_styles | 使用同一配置的多个已验证 receiptIds，检查各分类完整名称列表、核对客户保存确认、保存时间更新后刷新并重载原客户，逐 ID 回读 | 不发布；服务器 API 未独立验证，保存按钮是配置级动作，其他分类的手工修改无法全部检测 |

源码入口已注册；部署状态、输入通道加载与真实业务验收分开记录，不能因工具存在或模拟通过就报告新建或保存成功。

## 真实页面验收记录

2026-11-19 已通过同一 MCP 服务在真实客户配置中新建文本、引线、尺寸、标高测试样式各一项，逐项确认新 ID 和名称。随后在真实名称搜索框找到新建文本测试样式，字号从 16 改为 4，重新打开同一记录核对，其余已读取规范字段保持不变。四类新建保留各自规范面板的默认参数。

使用四个新建回执和一个连续文本修改回执保存一次；客户保存确认完成，保存时间更新，刷新后重新载入原客户及默认选中模板，再按原 ID 回读四条记录及文本字号 4。结果为 saved=true、persistedReadback=true、customerReattached=true；serverApiVerified=false。未发布，未执行前端更新或出图。公开记录不包含客户信息和真实记录 ID。

这轮证明四类新建、实际名称搜索、文本字号修改及配置保存回读可用；独立重命名、其他三类规范字段写入、完整跨页搜索和所有账号/页面版本仍待分别验证。

## 新建与修改

1. 搜索指定分类和名称，读取 complete；同名歧义、只读锁或无法完整检查时停止。
2. 每项任务使用唯一 requestId。先记录意图再点击新建；第一步是名称向导，第二步是该分类的规范面板，点击“完成”后才寻找新行。
3. 名称及字号使用扩展的限定浏览器输入通道，绑定配置、客户、分类及任务回执。首次增加该通道后重新加载实际浏览器扩展，不要求重新登录或载入客户。
4. 结果为 annotation-fields-verified 时记录 receiptId、分类和新行 ID；saved=false 仍是未保存。出现 needs-review 时先查看当前步骤和记录，不能换 requestId 再新建。
5. 名称向导尚未点击下一步时，可以用同一任务回执完成已打开步骤，不再次点顶部新建。参数不得改变。最终完成已尝试且结果不明时，不重放。
6. 修改前用搜索结果构造 expectedStyle={id,name}，changes 只包含实际要求的字段。fontSize 只用于 text，保持平台数值语义，不猜 px/pt/mm；修改后再次打开同一行检查字号及其余字段。

## 保存与核验

一轮多分类修改完成后，使用所有创建及连续编辑回执独立保存一次。核对原客户及配置确认框，观察新保存时间；刷新回到操作员自己的配置时，只重新载入原客户，不再次提交保存。原配置名、分类、ID、名称及本轮字号均需重新读取。

只在 saved=true、persistedReadback=true 时报告刷新回读通过；serverApiVerified=false 不能表述为独立服务器接口验收。保存确认已提交但结果不明时，保持待核验，不盲目重试。后续前端更新、图纸验收及发布另行报告。

新建、改名和规范字段的真实验收必须逐项记录；不把某类创建成功推为该类所有规范字段可写，也不把文本字号测试推广为引线、尺寸和标高规范修改已支持。
