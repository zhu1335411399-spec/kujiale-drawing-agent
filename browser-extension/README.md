# 浏览器扩展

本目录包含施工图配置独立扩展源码。完整包通过 Start.cmd 安装后，在 Chrome/Edge 加载安装目录中的 browser-extension。无需配对码。

两个账号使用独立浏览器用户配置，分别核对 pageId；页面访问、本机桥接和 AI 实际读取各自验证。首次加载需要使用者确认。

当前侧栏显示服务状态、当前浏览器的页面与账号，以及页面实际提供的账号 ID。会话、MCP 页面和标签页 ID 放在可展开区域，不与账号 ID 混用。后台目标客户 ID 没有读取证据时显示“未读取”。

日常界面已移除原始接口、编码配置读取及采集/探测按钮；研究用 MCP 功能保留。更新后关闭重开侧栏，仍显示旧界面时重新加载扩展。详见 [精简面板说明](../docs/extension-panel.md)。
