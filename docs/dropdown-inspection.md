# 下拉控件读取：第一阶段

以下保留早期研究记录。文中候选项采集、颜色探测及采集更新按钮已从当前日常界面移出；现有界面见 [精简面板](extension-panel.md)。历史按钮描述不代表当前仍有相同入口。

2026-11-13：新增纯 DOM 控件探测，作为 `drawing_read_config` 的 `controlInspection` 返回。仅在配置页调用，探测函数再限定线样式页的域名及路径。不新增保存或发布操作。

按表头定位线型、颜色、线宽，最多采样前三行，返回控件类型、ARIA 展开状态及关联弹层。原生 select 可读取 DOM 中的 options；自定义弹层只读取与目标控件通过 ARIA 关联的可见节点。所有自定义选项集合标记 `complete:false`，不把当前已选值当成全集。

此阶段不点击、不填入值、不触发 change、不滚动、不请求网页接口。颜色控件没有 ARIA 关联、虚拟列表未渲染等情况保持未知，不能猜测固定选项。需取得真实控件证据后再实现展开与滚动适配。

本机更新扩展文件后需用户重新加载扩展；重跑原有只读验证程序即可采集。报告包含客户数据，只保存在本机，不提交仓库。模拟 DOM 测试和真实采集验收分别记录。

## 第二阶段：显式触发候选项采集

扩展弹窗新增“只读采集候选项”按钮。只有用户点击才展开第一行的线型、线宽，按 ARIA 关联找到对应 Ant Select 弹层，逐段滚动并读取显示标签，随后关闭并核对整页表格可见文字、输入值和记录 ID。已打开的下拉框会导致拒绝开始，避免干扰用户操作。采集期间勿操作配置页。

结果只在当前扩展会话缓存 5 分钟，按标签页、URL 和配置来源文字核对后，随 `drawing_read_config.optionInspection` 返回；原生桥接无需新增服务路由或放宽命名管道权限。此入口是采集阶段的临时 UI 入口，不等于会话已能直接调用 MCP，也不是已部署的专用枚举工具。

遇到页面/表格值变化或弹层无法关闭即停止。没有选择、填写、保存或发布代码，不尝试自动回滚意外变化。`valuesUnchanged` 只表示本次 DOM 比对一致，不证明服务端没有变化。

观察到的标签与 DOM `data-value` 分开记录；没有 `data-value` 时不能把标签假定为接口值。到达滚动底部仍标记 `complete:false`，后续需验证懒加载、重复标签、服务端总量等情况。颜色仅返回首行控件结构供下一步适配，不打开或选择颜色。

本次模拟测试共 7 项通过；真实页面展开与采集结果待验证。自动搜索、跨网页分页、自动填写及保存继续保持未实现/未验证。

### 首次真实采集及关闭修正

真实采集观察到 53 个线型显示标签，滚动遍历到列表底部，表格原值一致；但弹层未成功关闭，按保护条件停止，线宽和颜色尚未采集，仍不能声称全集已验证。

关闭流程已修正：Escape 后等待退场动画；仍打开时向页面 body 发送外部 pointerdown/mousedown，不再切换下拉触发器，避免重新打开弹层。无法关闭时返回 `stopped-popup-not-closed`，与表格值变化分开报告。模拟测试新增 Escape 无效时的关闭与关闭失败时停止两项，共 9 项通过。修正后的真实页面验收待完成。

### 自动核对与独立颜色结构探测

采集返回 `readerBuild: options-close-fix-2`。普通只读验证报告增加 `optionValidation`；配置读取成功不能替代候选项验证。支持 `--require-options`，遇到旧版、过期、配置来源不符、弹层未关闭、原值变化或字段未完成时退出非零，避免误报成功。即使观察到的线型及线宽标签验证通过，仍标记全集证明、颜色适配及自动填写未完成。

颜色结构改为在 `drawing_read_config.controlInspection` 中独立采集，最多前三行、每行 30 个可见节点，输出类名、角色、标题、光标和背景色；不依赖候选项采集，也不点击颜色。当前组合模拟测试 15 项通过，真实运行状态以新报告为准。

### 线型/线宽真实验收与颜色面板探测

2026-11-13 10:50（上海时间）报告通过 `observed-labels-verified`：观察到 53 个线型、23 个线宽标签，两个弹层均关闭且表格原值一致。只是 UI 标签及遍历证据，不证明接口参数或所有版本的选项全集。

颜色单元格实测包含 `NewColorPicker-flex_*` 和可点击的 `ColorPickerPanel-colorBlock_*`，不是 Ant Select。新增独立“只读探测颜色面板”入口，只点击当前颜色触发器，读取新出现的颜色面板结构、当前渲染色块、输入类型和标签，随后发送外部按下事件关闭并对比整页表格文字、输入值和原色块背景色。没有点击候选色块、切换页签、改输入值或调用保存/发布。

结果缓存 5 分钟，随普通只读报告的 `config.colorInspection` 返回。颜色真实面板待验收，不声称颜色为固定有限枚举。自定义 RGB 等输入若存在，需要单独区分可枚举预设与可输入颜色范围。组合模拟测试共 20 项通过。

### 颜色第一模式真实验收

2026-11-13 10:55（上海时间）真实报告：`color-panel-probe-1` 返回 `panel-observed`、`closed:true`、`valuesUnchanged:true`。观察到 `ColorPickerPanel-colorPickerContainer_*`，包含 75 个 `ColorIndexPicker-pickerItem_*` 候选元素和 2 个 `ColorPickerPanel-button_*` 模式入口（其中 1 个为 active）。通用背景色探测计数 77 含容器背景，不能作为候选颜色数量；实际候选元素按 pickerItem 类计数为 75。

当前模式有索引输入控件，但色块的 title、ARIA 标签、data-index 和 data-value 未提供编号映射。不能按 DOM 顺序猜编号，也不能把 CSS RGB 当作服务端索引。另一个模式尚未打开，无法据此证明固定颜色全集或 RGB 输入范围。当前只完成安全的当前面板探测，不授权自动填写或宣称保存能力可用。

下一步适配应同时采集候选项的明确类名、模式标签及激活状态、索引输入的可访问性范围和邻近说明，形成按模式区分的数据契约；没有明确映射的预设保持未知。页面交互必须继续检查关闭和原值一致性。
