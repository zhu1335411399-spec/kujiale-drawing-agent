## 默认双端浏览器方案：Chrome + Edge

用户已选择：Chrome 登录内部账号，用于后端施工图配置；Edge 登录客户账号，用于前端施工图设计与验收。两个浏览器分别加载同一施工图桥接扩展，连接同一本机服务。任务开始通过 drawing_get_context 分别绑定两个 pageId，不能仅凭浏览器名称证明账号或客户归属。

后端使用内部账号时仍需确认目标客户及配置归属；前端确认目标企业模板，后台保存后执行“图纸&清单 → 设置 → 更新配置”，涉及自动标注时进入对应“编辑视图 → 自动标注”。实际页面连接、登录身份和配置关联尚需现场核验。

该方案作为默认使用流程暂存，不代表两个浏览器已经安装扩展或完成登录，也不触发 0.5.0 安装包更新。不同 Chrome 用户配置仍可作为备用方案。
