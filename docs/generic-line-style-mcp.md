# 通用新建线样式 MCP

工具：`drawing_create_line_draft`。

执行“新建样式 → 设置名称 → 选择线型 → 输入颜色索引并确认 → 选择线宽 → 回读”。
底层为浏览器页面操作，不依赖直接请求酷家乐保存接口。名称和各字段均为调用参数。

## 使用

先调用 `drawing_get_context`，确认只有一个预期配置页并位于线样式标签。
从实际页面取得 pageId、基础配置名称和右上角“来自于”标签，不能凭空填写。
请求例子中的目标字段是占位值：

```json
{
  "pageId": "<上下文返回值>",
  "requestId": "create-line-unique-001",
  "expectedConfigName": "<当前基础配置名称>",
  "expectedCustomerName": "<来自于后的标签>",
  "name": "示例线样式",
  "lineType": "DOT",
  "colorIndex": "255",
  "widthMm": "0.09"
}
```

## 输出与边界

成功状态为 `draft-fields-verified`，`style` 返回页面实际 ID、名称、线型、比例、颜色、线宽。
`saved`、`published` 均为 false。此工具不自动保存、刷新、发布或切换配置。
比例保持网页默认值，暂不支持指定比例。线型和线宽必须是网页实际下拉选项。
颜色为 0–255 索引；不支持 RGB。

失败由 MCP `isError:true` 报告，并保留已完成步骤和已创建行，禁止盲目重新新建。
每项新任务使用新 requestId。恢复同一任务必须使用相同参数和目标配置。
已经成功的请求不会重新新建。仅在同一已记录行仍与回读快照一致时允许恢复未完成编辑。
重名检查仅覆盖当前网页分页，不能宣称已检查整份配置。

这只是新建草稿能力。完整“新建并保存”需要单独验证保存与持久化回读，不能由草稿成功推断。
