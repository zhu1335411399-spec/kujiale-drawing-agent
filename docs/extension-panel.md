# 精简扩展面板

侧栏和旧弹窗使用同一套页面与账号视图。保留“刷新状态”“重新连接”、当前浏览器页面选择和头像账号读取，不修改网站配置。

## ID 的含义

| 字段 | 来源 | 不能替代什么 |
|---|---|---|
| 页面账号 ID | 前端头像账号菜单中实际显示的 ID | 不自动证明企业归属或后台目标客户身份 |
| 来源客户 ID | 后台读取器的真实配置归属字段；没有时显示未读取 | 不能从客户名称或前端同名账号推断 |
| 浏览器会话 ID | 扩展在当前浏览器用户配置保存的 clientId | 不是网站账号 ID |
| MCP 页面 ID | clientId 与实际 tabId 组合 | 不是配置 ID |
| 标签页 ID | 浏览器标签页编号 | 不是账号 ID |

账号 ID 在主卡片显示，连接标识收进可展开区域。未知字段明确显示“未读取”。当前浏览器的页面列表包含后台和设计页，不把另一浏览器未列出当作未登录。

打开面板或选择新文档时自动检测一次账号。刷新状态使用缓存；“更新账号信息”才明确发起重测。普通设计端不需要先进入施工图，账号读取不依赖施工图入口。名称与 ID 从同一账号头像菜单读取，账号 ID 需匹配明确的 ID 标签及相邻位置；缺少 ID 不阻止显示已读到的账号名称。

弹窗、侧栏和 drawing_read_frontend_account 共用当前浏览器工作线程中的检测器。相同标签页、相同文档的同时请求只执行一次；连续点击不排队、不反复悬停。检测超时停止等待，失败或没有头像也不会自动重试。重新加载相同 URL、跳转、关闭或休眠会清除对应旧结果；迟到响应不能覆盖新页面。缓存显示读取时间，超过 30 秒显示历史结果，默认不因过期再次悬停，需要时手动更新。缓存不证明当前登录身份或企业归属，开始前端业务验收前应明确更新并核对账号。

页面信息、账号显示和施工图状态分别呈现。施工图状态可显示普通设计端、编辑视图或布局图纸；“已进入施工图”不等于已选企业模板，也不代表更新配置或效果验证成功。同一文档内切换工作区时，点击刷新状态读取新工作区，账号可以继续使用带时间标记的结果。

## 移出的日常入口

- 原始接口记录、模板接口、编码配置接口读取。
- 网络采集开始/停止、线型候选项滚动采集、颜色面板探测。
- 专门为旧采集流程设置的扩展重载按钮、重复的连接状态脚本和暂停按钮。

研究用途的 MCP 诊断能力与源码保留，历史文档只作为研究记录。移出按钮不代表此前未解析的接口已修复，也不修改保存或发布能力。

面板获得焦点及每 8 秒的检查只读取连接状态，不触发账号悬停。无关标签页的创建、跳转、关闭不会清空当前账号或触发检测；相关页面事件合并处理。初次打开优先选当前活动设计页，避免被排在前面的后台标签页抢占。所有动态名称与 ID 用 textContent 呈现，不将页面文本当作 HTML。

本次新增共享后台检测模块，已加载的 Chrome/Edge 扩展需各自在扩展管理页重新加载一次，再打开侧栏。仅点重新连接不会刷新已导入的工作线程模块。无需卸载、修改权限、退出方案或重新登录。历史安装包不随此次源码更新重新发布。

真实页面已通过 MCP 从头像账号菜单读取到名称和可见账号 ID；面板展示、关闭页清理与迟到响应另有界面回归检查。该记录不声称已通过工具观察真实侧栏的像素渲染。

2026-11-19 已进一步在未打开施工图的真实普通设计端读取到目标企业显示名称及可见账号 ID；工作区标记为 design、drawingOpen=false。重复焦点事件、不相关标签、并发检测、超时和同 URL 重载已做针对性回归。新版共享检测器与真实侧栏的运行表现需在实际扩展重新加载后继续核验，不将回归检查数量当作业务验收证据。
