# 通用新建线样式草稿

## 目标绑定

1. 调用 drawing_get_context，选择明确的配置 pageId，确认已打开“样式配置 → 线样式”。URL 相同不保证子标签相同。
2. 核对基础配置名称及右上角“来自于”后的完整显示标签。名称未知、目标歧义或归属不明确时停止，不编造。
3. 将用户需求映射为 name、lineType、colorIndex、widthMm。名称为个性化输入，不固定为任何测试名。
4. 使用 drawing_search_line_styles 按名称查找并确认 complete=true，再清除搜索后新建。读取工具 drawing_list_line_styles 的 name 只过滤当前分页，不能声称检查了全配置。新建工具自身仍只做当前页重名检查，跨页预检由流程串联。

## 调用

使用 drawing_create_line_draft：

| 参数 | 规则 |
|---|---|
| pageId | 本轮上下文返回的页面标识 |
| requestId | 每项新任务唯一；8–100 位字母、数字、下划线或连字符 |
| expectedConfigName | 当前选中的基础配置完整名称 |
| expectedCustomerName | 来自于后的完整显示标签，不是推测的用户 ID |
| name | 非空样式名称，最多 100 字符 |
| lineType | 当前下拉实际存在的准确名称，如 DOT 或 DASHED |
| colorIndex | 0–255 的 CAD 索引色，字符串；不接受 RGB |
| widthMm | 正数毫米值，字符串，必须为实际可选项 |

比例保持网页默认值并在结果中报告；不能假定为 1。CONTINUOUS 下比例不可编辑的用户规则
不得推广为其他线型的默认数值。当前通用工具不接收比例参数。

## 结果与失败恢复

- 成功仅接受 status=draft-fields-verified。检查 style 的名称、线型、颜色、线宽，并用 drawing_list_line_styles 独立回读。
- saved=false、published=false 代表草稿未保存、未发布；明确报告，不称为完整配置完成。
- 返回 needs-review 时先读当前行和已完成字段。恢复同一任务使用相同 requestId、目标和参数，不能创建第二行。
- 未知新建结果、行 ID 或原值变化时停止。失败不是“没做任何修改”。
- 名称与颜色采用扩展限定的浏览器输入通道并失焦提交，不能把输入框暂存文字当作已提交；面板有唯一确认按钮时按观察到的按钮处理。
- 名称是点击后编辑；线型与线宽按属于该行的实际下拉选项选择，不能猜选项位置。
- 新建草稿回执不同于已有样式编辑回执，不能直接传给 drawing_save_line_style。需要后续实际编辑比例等字段时，按搜索快照调用 drawing_update_line_style，再用其 receiptId 独立保存。没有需要修改的字段时不为取得回执而重复写入；新建草稿直接转保存的通用入口仍需补齐。不能自动发布补救。

## 后续优先项

1. 将新建草稿回执安全交接给独立保存；已有样式编辑的独立保存合同见 [搜索编辑流程](line-style-edit.md)。
2. 可选比例参数，按 CONTINUOUS 与其他线型区别校验。
3. 将现有网页搜索工具的跨页重名检查整合至新建入口。
4. 将 requestId 与目标、参数完整绑定，并提升刷新后的未完成任务恢复能力。
5. 已有样式编辑现有独立工具；复制、删除、批量导入仍需分别适配与验收。
