# 施工图画面读取（后台模块待加载实测）

drawing_capture_frontend_view 只读当前已绑定账号显示证据、浏览器、方案标题与文档中的唯一可见施工图画布。需要画布没有被对话框遮挡，不选择图纸、不生成、不保存或发布。

普通 canvas 导出可能因 WebGL 绘制缓冲区被清除而得到纯黑或透明图。均匀画面返回不可读，不输出“没有红色”或“样式未生效”。目前普通画布路径已真实遇到此问题。

新增浏览器截图路径在扩展后台执行：预检 DOM 和账号证据，临时附加自己的调试会话，仅截取目标画布在视口中的区域，捕获后重新核对文档、标题、画布及位置，最后清理自己的会话。已有调试连接时不接管或断开他人的调试。使用扩展原有 debugger 权限，不增加权限。

图像有响应大小上限，MCP 返回 metadata 文本和原生 image 内容，便于 Host/Codex 直接观察。captured 不代表 effectVerified；实际还要确认图纸种类、目标橱柜、浅深主题、继承及视图自定义覆盖。不能由局部红色像素自动判定某个对象的样式正确。

首次部署新增后台模块后，仅重新连接不能加载它，需要在目标设计浏览器的扩展管理页重新加载一次。旧工作线程返回 extension-reload-required，不再回退为全黑画布并误报成功。当前合成截图尚未完成真实页面验收。


2026-11-20 已在真实设计端通过浏览器合成截图读取平面布置图，观察到两处柜体的红色加粗边线及黑色墙线，完成当前视图的颜色对照验收。不同绘图版本支持 scene2d 与 scene-2d 两类画布容器；同一文档的模块路由切换不视为换号，但仍核对来源、文档时期、账号名称、标题和截图前后状态。截图采用画布内稳定区域，以免浏览器调试提示条引发重排而误丢图。该证据不推广到其他视图，未测量图纸最终物理线宽。
