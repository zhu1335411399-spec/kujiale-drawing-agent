# 线样式：共性结构与客户个性化

## 适用范围与证据

仅用于施工图后台“样式配置 → 线样式”，与参数化模型工具分开。
表格列与业务操作流程作为共性规则；样式集合、名称、数量、行 ID 和已选参数值按账号、客户、基础配置分别读取。
2026-11-12 的本机验证脚本已通过既有 MCP 处理器读取上下文、配置状态及当前页面前 10 条线样式；这不代表聊天客户端直接接入完成。
2026-11-13 用户确认线型、颜色、线宽有固定选项，并可通过网页“搜索线样式名称”查找。选项全集、搜索触发方式、跨页范围及具体写入流程尚未实测。
不在本文件保存客户实际数据、账号标签、客户企业名称、会话标识或私有读取结果。

## 共性字段合同

| 页面列 | 通用含义 | 读取与定位规则 |
|---|---|---|
| 序号 | 当前列表的展示顺序 | 不作为稳定 ID；搜索、翻页、排序后可能变化 |
| 线样式名称 | 客户定义的样式名称 | 不硬编码名称；从当前目标配置读取；支持同名歧义 |
| 样式预览 | 当前线样式的视觉展示 | 不凭预览反推精确参数；尚无结构化预览读取能力 |
| 线型 | 控件提供的线型选项 | 读取实际已选值；编辑前核实控件真实可选项 |
| 线型比例 | 适用线型的比例参数 | 保留实际数值或空值；不把空值默认为 1 或 0 |
| 颜色 | 当前选择的颜色 | 保留页面原始表示；索引色与 RGB 不混为同一编码 |
| 线宽 | 线宽参数，当前观察表头为“线宽(mm)” | 保存原值及单位；编辑前核实当前控件选项 |
| 操作 | 页面该行提供的操作入口 | 不能凭列存在就认为已实现编辑、删除、保存或发布 |

“现样式名称”“现款”在当前用户说明中分别按“线样式名称”“线宽”理解，不自动作为真实页面表头别名。
读取器应基于表头确定列位置，不依赖固定列序；出现缺列或多义别名时返回结构变化，不能悄悄读错列。
现有读取器只输出 id、name、lineType、scale、color、widthMm；序号、预览、操作入口尚未封装为返回字段。
固定选项的范围来自当前控件和版本，不把某一账号的已选值当作全平台枚举全集，也不擅自假设所有账号允许自定义颜色或线宽。

## 个性化目标定位

1. 调用 drawing_get_context 绑定配置 pageId，读取配置名称、客户来源和状态；任何未知身份或归属保持待确认。
2. 调用 drawing_list_line_styles 读取当前配置的数据；不复用其他账号的样式 ID 或名称。
3. 有行 ID 时使用配置范围内的行 ID；只有名称时先精确核对，同名项结合配置及其他字段消歧，不能直接操作第一条。
4. 在当前返回结果找不到时，先检查工具分页 offset/limit、网页分页和网页搜索状态；不能因此报告“该账号不存在此样式”。
5. 对个性化名称，使用用户提供的完整名称在网页搜索框查询，再重新读取并核对。搜索无结果时核对拼写和过滤条件，不猜测替代名称，不擅自新建。
6. 网页搜索输入、清空和触发动作在自动适配器实测前由用户完成。读取后记录搜索词、网页页码、范围及是否唯一命中；不把触发搜索当作配置保存。
7. 切换账号、客户、基础配置或页面后重新绑定，废弃旧行定位；搜索状态变化后也应重新获取目标行。

## 现有 MCP 与搜索边界

- drawing_get_context：定位各浏览器页面。可访问不证明账号、客户归属或“图纸&清单”已打开。
- drawing_read_config：读取页面上的配置字段；配置名称读取曾返回空，不能编造名称或仅凭状态文字认定已修复。
- drawing_list_line_styles(pageId, name?, offset?, limit?)：只读当前已渲染网页分页，默认 10 行。name 是本地子串过滤，不会填写网页搜索框，不会查询全部网页分页。
- 当前不新增只为文档存在的 MCP 工具名。网页搜索与固定选项读取适配器实现、测试后，再分别决定扩展原工具或增加专用工具。
- 不把读取 DOM 的结果称为接口返回；直接调用网页业务 API 需要另行核验请求参数、授权和响应合同。

## 后续实现与验收

- 读取层：按表头映射核心字段；字段缺失明确报错；支持列序变化、个性化名称、同名样式、空比例及不同颜色表示。
- 搜索层：验证网页搜索入口、触发时机、完成信号、清空行为和搜索范围；既有 name 参数继续明确标为当前页过滤，避免语义偷偷改变。
- 选项层：从实际控件读取并记录选项及来源；枚举不可读时保持未验证，不硬编码推测的完整列表。
- 编辑层：核对客户/配置/行目标及允许选项后才写入；无权限、无唯一目标、未知选项时停止。
- 修改完成独立保存并回读；发布只按用户明确要求独立触发。当前保存/发布适配器仍返回未执行，不得报告完成。
- 后台保存后，前端以目标企业模板执行“图纸&清单 → 设置 → 更新配置”；涉及自动标注再进入“编辑视图 → 自动标注”。行业模板保持全球通用，不承担客户个性化验收。
