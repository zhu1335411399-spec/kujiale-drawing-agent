# 线样式数据合同

线样式名称及内容属于客户个性化配置，不能硬编码客户样式。名称、线型、线型比例、颜色及线宽是当前列表可读字段；下拉选项必须从目标行实际关联的控件读取，不能把某次观察当作完整选项全集。

drawing_list_line_styles 只读取当前渲染分页，name 是本地过滤。跨页查找名称使用 drawing_search_line_styles，检查 complete 和行 ID。搜索、已有样式编辑及保存见 [完整流程](line-style-edit.md)，新建草稿见 [新建流程](line-style-create.md)。

线样式供对象配置等引用，但当前引用关系尚未自动读取。注释样式的文本、引线、尺寸、标高四类需要分别适配；线样式读取或编辑成功不代表它们已支持。

CONTINUOUS 下线型比例不可编辑，其他线型按实际控件设置正数比例。颜色索引和 RGB 是不同输入模式；当前自动编辑仅支持 CAD 索引色。
