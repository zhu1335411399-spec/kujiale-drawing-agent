# 注释样式与通用配色

## 工具与流程

调用 drawing_get_context 绑定客户、配置及 pageId，再使用 drawing_inspect_style_settings：

1. 传 section=annotation、action=inspect；需要分类时传 annotationKind=text、leader、dimension 或 elevation。读取实际行 ID，不按列表序号猜目标。
2. 用已观察的 styleId 调用 action=open-editor，核对 dialogs[].editorType 与目标分类一致。分别读取该面板的字段，不能套用文本样式的结构。
3. 从 section、context、contextPath 和面板分组区分同名字段；section 来自控件之前实际可见的分组标题，不是按参数位置猜测。尤其不能把尺寸线与尺寸界线的“颜色（浅底）”混成一个参数。缺少分组、图标或数值代码语义时保留未知。
4. 只读完成后用 close-editor 取消本工具打开的面板，不点“完成”。已有用户面板只读查看，不擅自取消用户的未提交编辑。
5. 读通用配色时传 section=general、action=inspect，只读取当前选中项。

只读检查仅覆盖可见列表及面板，complete=false；新增注释业务工具的调用合同见 [新建与保存](annotation-write.md)。完整分页搜索及多数规范字段仍未适配。源码注册、部署与实测结果分别核对，不得用线样式回执保存注释样式。

## 分别识别四类编辑内容

| 分类 | 实际读取的规范字段 | 关联与待确认项 |
|---|---|---|
| 文本样式 | 字号、浅底/深底颜色、背景遮罩、边框、水平/垂直对齐、引线样式、连接位置、默认仅文本/带引线及深浅预览 | 引用引线样式；字号单位、范围及与输出尺寸关系尚未确认 |
| 引线样式 | 浅底/深底颜色、引出点样式、引出点大小（工具）、引出点大小（下载） | 当前读取的下载大小控件禁用；禁用条件未知，不推断为权限，也不解除禁用 |
| 尺寸样式 | 文本样式、后缀/显示单位、尺寸线截止符样式及深浅颜色、尺寸界线深浅颜色、尺寸界限长度（倍字高） | 字号来自引用文本样式；改变字号可能影响依赖字高的界线表现；同名颜色须区分所属分组 |
| 标高样式 | 文本样式、后缀/显示单位、标高符号样式及深浅颜色、引线样式、默认带引线/无引线 | 同时引用文本与引线；不能把名称当作字体或符号参数 |

图标型选项的可读语义、下拉全集、数值单位及限制未逐项展开，不猜测代码对应的方向或符号。预览不是前端应用、下载或打印效果的验收证据。

## 名称与参数

- 重命名只改名称并保留原 ID；编辑修改规范。不能用删除再新建代替重命名。
- 沿用用户 T、L 来自 Text、Line 的命名约定，T_3 表示文本字号 3；L 类指引线样式，不等于线样式页的线型。
- 从面板读取字号和引用真值；名称解析不是字段证据。名称与参数不一致时提示差异，不擅自同时改名。
- D、H 等仅作客户命名，不未经核对解释后缀。搜索先限定分类，再按名称与 ID 定位；同名跨类记录是不同目标。
- 已观察“重命名”操作；用户补充的直接点击名称改名路径尚未提交实测，不能报告已接通。

## 字号、背景与配色

- 用户指定平台字号数值时回读原值与目标值；用户要求物理字高或打印效果时，先确认单位、视图/图纸比例及输出关系，不直接当作 px、pt 或 mm，不凭名称猜单位。
- 按正文、尺寸、标高、说明的角色检查层级与可读性。屏幕预览不足以证明出图效果；字号改变时检查依赖字高的尺寸界线等表现。
- 背景遮罩、边框与深浅配色分别核验。遮罩对底图线条的遮挡、边框是否合适需在实际图纸中检查，不把“显示遮罩”当作深底主题。
- 沿用用户约定的“深浅分别配置”作为工作流默认，先读现有配置。当前客户选中该项不代表所有账号的系统默认；现有值不同时先报告，不静默切换。
- 浅底、深底分别盘点文字、引线、尺寸线、尺寸界线及标高符号颜色。空值、“-”或只有色块时保留证据，不自动解释成颜色 0、继承或未配置。

## 引用与验收

已观察的正向引用：文本样式 → 引线样式；尺寸样式 → 文本样式；标高样式 → 文本样式及引线样式。这不等于已读出全部引用 ID 或反向使用位置。

修改共享规范前核对授权分类、样式及字段；报告可能影响的标注/图纸文本，未读到的使用范围标记 unknown。不根据名称拼接引用 ID，不自动替换其他分类引用。

后续写入工具分别支持新建、保留 ID 的重命名与字段编辑，记录原值、目标值及回执；独立保存确认后刷新并重新绑定客户回读，再到前端更新配置验收。文本检查文字与遮罩，引线检查工具/下载大小，尺寸检查文本、尺寸线/界线及倍字高，标高检查文字、符号及引线。发布单独按用户明确要求执行。
